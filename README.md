# Bururan

> Suplemento para la salud masculina y prostática con maca peruana, saw palmetto, licopeno y zinc.

**[Visitar bururan.co](https://bururan.co)**

## Sobre este proyecto

Este repositorio contiene el sitio web de [Bururan](https://bururan.co), un recurso de salud basado en evidencia científica enfocado en **Salud Masculina**.

### Ingredientes clave

Maca negra (*Lepidium meyenii*), saw palmetto, licopeno, zinc picolinato, selenio

## Tecnología

- HTML5 + CSS3 (sitio estático)
- Hospedado en GitHub Pages
- Sin dependencias de JavaScript frameworks
- Optimizado para Core Web Vitals

## Evidencia científica

Todo el contenido está respaldado por:
- Estudios clínicos publicados en PubMed
- Monografías de la EMA (European Medicines Agency)
- Guías de la OMS sobre plantas medicinales
- Base de datos TRAMIL de plantas del Caribe y Latinoamérica
